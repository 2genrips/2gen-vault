Support

Use this page for release support information, troubleshooting and data-control guidance.

Support contact: configure supportEmail or supportUrl in the production config before store submission.

Quick troubleshooting

If live stock or alerts stop updating, open Tools → Settings → Launch Center and run diagnostics. The Launch Center shows Worker, Watch Engine, billing and entitlement readiness separately.

Scanner

Camera permission is only needed when using the card scanner. Keep the full card inside the frame, reduce glare and make the card name plus collector number readable.

Inventory accuracy

VaultSignal never invents a shelf count. If a source reports availability but not quantity, the app labels the quantity as not supplied.

Delete data

Tools → Settings includes “Delete server Watch data” and “Delete all app data.” The first removes Watch Engine server records for this installation; the second also clears local app storage.

Premium

The release candidate keeps Premium Preview enabled for testing. The production store build must disable Preview and connect Apple/Google billing plus secure entitlement verification.
