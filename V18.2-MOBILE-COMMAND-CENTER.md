# VaultSignal v18.2 — Mobile Command Center

v18.2 simplifies the Android/PWA header without removing any collector systems.

## Mobile header
On phone-width screens the individual 2GEN, Journey, Graph, Grail IQ, Signals and Live Community pills are hidden from the top bar and replaced with one **COMMAND** button.

The Inventory Service/cloud status remains visible.

## Command Center sheet
The native-style bottom sheet launches:
- Grail IQ
- Signal Network
- Card Journey
- VaultGraph
- Live Community
- 2GEN Creator Command

It also adds direct quick actions for:
- Find Stock
- Scan & Value
- Search Market
- My Vault

The sheet is mobile-only. Desktop/tablet behavior remains unchanged.

## Home density
Signal Network and Grail IQ home alerts are compacted on phones so the core dashboard tools appear sooner without deleting the alerts.

## Data safety
No collection, account, Supabase schema, entitlement or community data is migrated or replaced by this release.

## PWA
Cache: `vaultsignal-mobile-command-v182`

Public API:
`window.VaultSignalMobileCommand={open,close,launch,version:'18.2.0'}`
